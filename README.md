# Fissure Tracker

**OpenCV AI Competition 2026 (powered by AWS), Agentic Vision Award. Team members: Anuj and Asron.**

A wall-crack growth monitor. OpenCV 5 measures a crack in millimetres from a phone photo with a printed marker,
and an AI agent (Amazon Nova 2 Lite on Amazon Bedrock) uses those measurements to decide the next step. It can
ask for a retake or close-up, save the reading, or ask a structural engineer to approve.

The code is in [`fissure_tracker/`](fissure_tracker/README.md).
